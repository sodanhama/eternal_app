# Eternal App

I made this app using Flutter to learn the basics of app development and using emulators.

I took help from YouTube tutorials, especially ones from Mitch Koko and the Flutter documentation.

It features a login page, a signup page, a home page, settings, profile, and the ability to post and view other posts.

I used Firebase for authentication.

Download it here: https://github.com/sodanhama/eternal_app/releases/tag/app
